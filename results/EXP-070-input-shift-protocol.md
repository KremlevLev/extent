# EXP-070 — frozen composition and matched-input diagnosis

Registered before TPU execution. This is a diagnostic experiment, not a new recovery method or a claim that sequential calibration works.

## Why

EXP-069 completed but did not recover useful whole-model quality. User hypothesis H3.4 suggests that locally prepared Mamba blocks fail on inputs generated by preceding replacements. H1.2 additionally motivates separating dt/decay/angle gradients. We measure these phenomena before changing training.

## Fixed protocol

- Qwen3-1.7B and EXP-069 prepared Mamba endpoints, seeds 123/456. Restore validated parameter hashes directly from HF. No large PC upload, no preparation retraining, no optimizer, no parameter updates. Trained step-3072 models are NOT used; probes diagnose freshly composed models only.
- Final retained GQA is fixed at `[6,13,20,27]`. Replace the first 0/1/4/12/24 positions from the ascending complement of that set. Intermediate models are nested diagnostics, not alternative candidate allocations. Replacement count and depth are confounded along this path: do not claim a universal density threshold.
- Two WikiText-2 validation windows, base token offset 65,536; each 256-token window is also evaluated on its first 64 tokens. Two seeds x five counts x two lengths x two windows = 40 probes. Text checksum is locked on resume. This small diagnostic sample is not a generalization benchmark or 40 independent replications.
- Objective gradient: teacher-to-student KL, temperature 2, plus CE weight 0.1, exactly the full-recovery objective. Gradients are measured before optimizer/clipping; both norms and nonfinite flags are retained. No gradient update is applied.
- For every substituted layer, compare student and teacher decoder contributions on (a) the same original Qwen input and (b) the same input produced by the hybrid prefix. Subtract residual identity from both outputs before relative-L2 normalization. Save absolute error RMS, target RMS, input drift and activation RMS to expose small-denominator artifacts.
- Matched local executions use the same compilation context. Separately record their discrepancies from full-model execution to distinguish numerical effects from input drift. V1's BF16-only guard and v2's overly strict FP32 control both stopped before Mamba probes. Version 3 runs both all-GQA wrappers jointly under JAX's highest matmul precision, records relative L2 at every hidden layer, and uses observed-background sanity bounds: absolute NLL difference <=0.005, absolute KL <=0.001, logits relative L2 <=0.005, and maximum hidden relative L2 <=0.005, all finite. These are implementation-corruption guards, not equality claims or statistical equivalence margins. BF16 forward/gradient finiteness remain required; BF16 NLL/KL discrepancies stay reported. Effects comparable to numerical background cannot be treated as resolved.
- Save every parameter's gradient norm, finite flag and maximum; top-20 parameters; squared-norm shares by layer/submodule. Split packed Mamba input-projection norms into gate/value/B/C/dt/decay/trapezoid/angle without double-counting those components in global shares.

## Interpretation and next decision

Systematically larger matched-input errors on hybrid inputs would support input-distribution sensitivity, not prove it is the sole cause of failed recovery. No change, or dominant gradient pathology without strong input sensitivity, should redirect work toward dynamics/optimization instead. Results alone do not establish that sequential calibration improves NLL. Such an intervention needs its own matched preparation budget and held-out full-model recovery comparison. Initial probes cannot explain all later training failures.
