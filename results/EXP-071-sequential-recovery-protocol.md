# EXP-071 — matched sequential input-distribution recovery (pre-registered)

Date: 2026-09-07. Status: implementation complete; no TPU result observed yet.

## Question

EXP-070 found that independently recovered Mamba blocks fail increasingly when their inputs come from an upstream hybrid prefix rather than Qwen. EXP-071 tests the causal intervention: does training each new block on the residual stream it will actually receive improve composed language-model recovery?

## Frozen design

- Source: pinned `Qwen/Qwen3-1.7B-Base`; retained GQA plan `[6,13,20,27]`.
- Nested path: first 12 non-attention layers in model order: `[0,1,2,3,4,5,7,8,9,10,11,12]`.
- Seeds: `123,456`; 1,024 Lion updates per added layer; only the current Mamba subtree trains. Qwen norms, MLP, embeddings, head, retained GQA and earlier Mamba endpoints are frozen.
- Every arm/layer starts from the exact matching EXP-069 prepared endpoint, verified by checkpoint SHA-256. The arms receive equal updates and use the same underlying pinned text.
- Training text: 128 windows of length 64 from WikiText-2 train offset 2,359,296. Evaluation: eight windows of length 256 from WikiText-2 test offset 32,768.
- Objective and precision: relative MSE of the learned decoder contribution after subtracting the shared residual identity, accumulated in FP32; BF16 weights, compute and gradients with stable gradient diagnostics. Lion LR `3e-5`, warmup 64, cosine decay, no weight decay, global clip 1.0.

## Matched arms

- `TEACHER`: extra recovery on natural Qwen residual inputs.
- `ONPOLICY`: recovery on residual inputs generated by that arm's already converted hybrid prefix.
- `MIXED`: equal natural and on-policy example pools, protecting the source distribution while adapting to deployment inputs.

For all arms the target is produced by the same frozen standalone Qwen decoder block, at the same batch shape, conditioned on the corresponding input. This avoids treating standalone-versus-full-model lowering differences as a recovery effect.

## Endpoints and gate

Held-out whole-model NLL, excess NLL, forward KL and top-1 agreement are measured after 1, 4, 8 and 12 replacements. The primary gate requires `MIXED` to beat equal-update `TEACHER` in final held-out NLL and milestone NLL-difference AUC at both seeds. `ONPOLICY` is a mechanism arm, not part of the strict primary gate. Frozen EXP-069 endpoints are also evaluated at each milestone as a no-extra-update reference.

A pass establishes that deployment-distribution recovery improves this 12-layer sequential path. It does not establish full 24/28 replacement recovery, the final 14B architecture, MLA quality, long context or inference throughput.

## Durability and runtime

Each completed layer is an atomic checkpoint uploaded to the configured private HF dataset. Upload failure stops the campaign before dependent work begins. A rerun restores exact-contract endpoints and continues. Compact JSON and Markdown summaries are updated after every stage; Telegram reports start and terminal state.
