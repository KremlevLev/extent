# EXP-104: одна Kaggle-сессия, TPU v5e8, до 8 часов

Обнови checkout до текущего main через существующую подготовку ноутбука.
Верхние ячейки установки, входа в GitHub/HF и настройки JAX сохраняются.
Нужны прежние secrets `HF_TOKEN` и `EXTENT_HF_CHECKPOINT_REPO` (HF dataset).
Новых обязательных пакетов нет. Запускать в том же процессе ноутбука:

```python
from scripts.m3q_paper_decoder_recovery_campaign import main

result = main([])
print("status:", result["status"])
print("gate:", result["aggregate"])
print("HF uploads pending:", result["pending_slots"])
```

Если верхние ячейки уже потратили30 минут из8h, вместо `main([])`:

```python
result = main(["--max-wall-hours", "7.5"])
```

По умолчанию6.5h на загрузку, проверки, компиляцию и обучение;1.5h оставлено на
большие состояния и HF. Сессия запускает контроль ADAPTER-CE и полный DECODER-CE
для seed123/456, чередуя горизонты512/1024/2048. Источник — фиксированные098
protected-r32 final16384. CE без KL; все внутренние слои открыты только в основном
варианте, embeddings/readout заморожены. AdamW1e-5, общий warmup/cosine.

Первый запуск автоматически проверяет реальные хеши текстов и всех исходных
бинарных checkpoint, после чего загружает модель. Несовместимые состояния,
отсутствующий источник и недостаточную память не заменяет другим стартом.

Отправь ОБА файла из `/kaggle/working/output/`:

- `extent-m3q-paper-decoder-recovery-summary.txt`
- `extent-m3q-paper-decoder-recovery.json`

Полный JSON нужен для пооконного сравнения и разбора ресурсных проблем.
Состояния автоматически лежат в HF под
`experiments/exp104-paper-decoder-recovery/checkpoints`; вручную скачивать их не надо.
Тот же вызов продолжает совместимые веса, моменты Adam и номер окна. Если HF
не успел принять локальный checkpoint, новый runtime восстановит последний
полностью загруженный, а не недоступный локальный прогресс. `pending_slots=[]`
означает отсутствие незагруженных состояний; дополнительно проверь отсутствие
`summary_sync_error`/`durability_error` в JSON.

Для повторной отправки сохранённых локальных файлов без обучения:

```python
result = main(["--sync-only"])
```

Один checkpoint полного decoder — около16.4GB; два состояния плюс временное
сохранение требуют десятков GB диска. Код проверяет место, RAM и HBM, записывает
память компилятора и время загрузок. Оценка памяти12.32GB/устройство — локальный
расчёт с запасом, НЕ измерение на TPU. Полные8h не гарантируют завершение всех
ветвей; при `deadline_partial` основной gate остаётся `None` и нужен точный resume.
В случае ресурсного отказа пришли полный JSON/сообщение ошибки, не меняй параметры
в обход протокола. Код локально проверен на CPU и восьми виртуальных устройствах;
реального TPU-результата пока нет.
